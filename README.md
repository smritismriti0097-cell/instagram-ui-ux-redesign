# Instagram UI/UX Redesign

## Project Overview
This project focuses on evaluating and redesigning selected screens of the Instagram Android application to explore improvements in usability, visual consistency, navigation, and accessibility.

## Project Objectives
- Evaluate the existing Instagram user interface.
- Identify usability issues and areas for improvement.
- Redesign selected application screens.
- Apply accessibility-conscious design practices.
- Create an interactive prototype and conduct basic usability testing.

## Redesigned Screens
The project includes four redesigned screens:
1. Home Feed
2. Reels
3. Explore
4. Profile

## Tools Used
- Figma – UI design and interactive prototyping

## Accessibility Considerations
- 44 × 44 px interactive touch-target frames.
- 30 × 30 px visible icons.
- Focus, selected, and pressed states.
- Attention to text readability and visual contrast.

## Usability Testing
The interactive prototype was informally tested by two participants, focusing on navigation between the four redesigned screens.

## Project Scope
This is a focused redesign of four selected Instagram screens, not a complete redesign of the application.
